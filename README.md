# Muskrat version 1.0

## Що це таке?
  * Muskrat — це свіжий погляд на класичне тамагочі, де ми інтегрували популярну сучасну концепцію відстеження часу (Time Tracking). 
    * Потрібен інструмент для керування часом? -Використовуйте Muskrat! 
    * Маєте СДУГ - Muskrat! 
    * шукаєте візуального помічника? -M-m-mu.. Так! Muskrat!
  
* Це мінімалістична програма, що займає лише 300x300 пікселів на вашому екрані, дозволяючи вам стежити за вашою продуктивністю та станом вашої кішочки без відволікання.

## Як це запустити?
  Програму рекомендується запускати, використовуючи файл Map.exe

## Як це компілювати? 
* Завантажити бібліотеки:
    * SDL2-2.30.11
    * SDL2_image-2.8.2
    * SDL2_ttf-2.24.0
* Розмістіть усі необхідні .json файли (такі як tasks.json, c_cpp_properties.json тощо) у папці .vscode вашого проєкту.
* Компіляція конкретного файлу
  Відкрийте файл tasks.json
  Змініть ФАЙЛ.c на назву вашого вихідного файлу (наприклад, Main_Screen.c).
  Змініть ФАЙЛ.exe на бажану назву виконуваного файлу (наприклад, Main_Screen.exe).
   
**Все це для версії mingw (x86_64-w64-mingw32**
